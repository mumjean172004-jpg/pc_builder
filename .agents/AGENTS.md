# Project-Scoped Customization Rules for PC Builder Pro

## 📋 Project Report Layout Rules (ปริญญานิพนธ์)
Whenever creating, editing, or analyzing draft document chapters for the project report (located in [07_document](file:///c:/Users/Kanomjean/Downloads/project/KnowledgeBase/07_document)), follow the formatting and layout guidelines defined in [ProjectReport_Template.md](file:///c:/Users/Kanomjean/Downloads/project/KnowledgeBase/07_document/ProjectReport_Template.md).

### Crucial Standards:
1. **Chapter Formatting Notes:** Add a notice/guide at the beginning of each draft chapter markdown detailing page layouts for Microsoft Word (e.g., margins, font size 20pt bold for Chapter title, 18pt bold for headings, 16pt for subheadings and body text, TH Sarabun New/PSK font, etc.).
2. **Standard Subsections Structure:**
   * **Chapter 1:** Must cover exactly:
     - 1.1 ที่มาและความสำคัญของปัญหา (Background & Significance)
     - 1.2 วัตถุประสงค์ของโครงงาน (Objectives)
     - 1.3 ขอบเขตของโครงงาน (Scope - Member, Admin, Core Engines)
     - 1.4 ประโยชน์ที่คาดว่าจะได้รับ (Expected Benefits)
     - 1.5 วิธีการดำเนินโครงงาน (SDLC Methodology Phases)
     - 1.6 เครื่องมือและภาษาที่ใช้ในการพัฒนา (Tech Stack, Hardware/Software tools)
     - 1.7 ระยะเวลาและแผนดำเนินโครงงาน (Gantt Chart Table)
   * **Chapter 2:** Must cover exactly:
     - 2.1 แนวคิดพื้นฐาน (Concepts)
     - 2.2 หลักการออกแบบเว็บแอปพลิเคชัน (Architecture, Responsive, Glassmorphism)
     - 2.3 เครื่องมือและภาษาที่ใช้
     - 2.4 ทฤษฎีที่เกี่ยวข้อง (JWT, Indexing, WebSockets, Transactions/Rollbacks)
     - 2.5 งานวิจัยที่เกี่ยวข้อง (Literature review of at least 3-4 peer-reviewed publications with details on how they are referenced in the codebase)
   * **Chapter 3:** Must cover exactly:
     - 3.1 การศึกษาข้อมูลและสถาปัตยกรรมระบบ (3-Tier architecture & table schemas)
     - 3.2 การออกแบบระบบและไดอะแกรมการทำงาน (Flowcharts, Use Case, ERD, Sequence Diagrams, Wireframes)
     - 3.3 การพัฒนาเว็บแอปพลิเคชัน (Implementation details)
   * **Chapter 4:** Must cover exactly:
     - 4.1 ผลการพัฒนาระบบ (Screenshots & descriptions of actual UI)
     - 4.2 ผลการทดสอบฟังก์ชันและประสิทธิภาพ (Functionality checklist table, accuracy calculations, deviation errors, etc.)
   * **Chapter 5:** Must cover exactly:
     - 5.1 สรุปผลและวิเคราะห์โครงงาน
     - 5.2 ปัญหา อุปสรรค และข้อเสนอแนะ
3. **Draft Updates:** Keep all files under the exact naming convention: `Chapter1_Introduction.md`, `Chapter2_LiteratureReview.md`, `Chapter3_Methodology.md`, `Chapter4_Results.md`, `Chapter5_Conclusion.md`.
