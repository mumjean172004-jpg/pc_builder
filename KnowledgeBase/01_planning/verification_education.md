## Educational Content

### Part 1: Serial Number Verification

**What is Serial Number?**
- Unique identifier for each device
- Usually on device body or inside
- Proves authenticity

**How to Check Serial Number?**

**For Laptops/Desktops**:
- [ ] Look on bottom of device
- [ ] Check inside battery compartment
- [ ] Check on bezel of screen
- [ ] Compare to original packaging

**For Phones**:
- [ ] Go to Settings → About → Serial Number
- [ ] Or find on phone back (physical marking)
- [ ] Compare to original box

**Verify Serial Number Online**:
- [ ] Go to manufacturer's website
- [ ] Enter serial number
- [ ] Check: Model matches? Warranty status?
- [ ] Red flag: Serial not found in system

### Part 2: Check System Information

**For Windows Computers**:
Step-by-step guide:
1. Click Windows button + R
2. Type: `msinfo32`
3. Take screenshot
4. Check:
   - Processor type & speed
   - Total RAM
   - System manufacturer
   - Model
   - Windows version

**For Mac**:
Step-by-step guide:
1. Click Apple menu
2. Select "About This Mac"
3. Take screenshot
4. Check:
   - Processor type
   - Memory (RAM)
   - Mac model
   - Serial number

**For Phone**:
Step-by-step guide (Android):
1. Go to Settings
2. About Phone
3. Take screenshot
4. Check: RAM, Storage, Android Version

Step-by-step guide (iPhone):
1. Go to Settings
2. General → About
3. Take screenshot
4. Check: Model, Storage, iOS Version

### Part 3: Test Device Performance

**Basic Performance Tests**:

1. **Power On Test**
   - Does it turn on immediately?
   - Does it take long time to boot?
   - Any strange sounds?

2. **System Diagnostics**
   - Windows: Windows Diagnostics Tool
   - Mac: Apple Diagnostics
   - Show screenshots of results

3. **Storage Check**
   - How much storage is used?
   - How much is free?
   - Any SMART warnings? (Hard drive health)

4. **RAM Test**
   - Open Task Manager (Windows) or Activity Monitor (Mac)
   - Take screenshot of total RAM
   - Check: Is it matching claimed specs?

5. **Battery Health** (Laptop/Phone)
   - Windows: `powercfg /batteryreport`
   - Mac: Hold Option + Click Battery Icon
   - Check: Design capacity vs Actual capacity
   - % Health should be 80%+

### Part 4: Port & Connectivity Check

**Test All Ports**:
- [ ] USB ports (plug in flash drive, check detection)
- [ ] Audio jack (plug in headphones, play sound)
- [ ] Charging port (plug in charger, show charging indicator)
- [ ] HDMI/Display port (connect monitor if available)
- [ ] Keyboard/Trackpad (test all keys, mouse movement)

**Screenshots to Take**:
- Device Manager showing all ports
- Audio playing in headphones
- Monitor connected and working

---

### Part 5: Spot Common Problems

**Warning Signs ⚠️**:

- ❌ Serial number not found online
- ❌ Specs in system don't match description
- ❌ Storage capacity less than claimed
- ❌ RAM not detected fully
- ❌ Battery health below 80%
- ❌ Strange sounds during startup/running
- ❌ Overheating during basic tasks
- ❌ Screen has dead pixels or cracks
- ❌ Keyboard/trackpad keys not responding
- ❌ Device can't boot into OS
- ❌ Error messages in diagnostics
