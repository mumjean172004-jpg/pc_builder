# Feature List

## Core Features
- ระบบสมัครสมาชิก / Login
- ระบบแสดงสินค้า
- ระบบลงขายสินค้า
- ระบบค้นหา / กรองสินค้า
- ระบบจัดสเปคคอม (PC Builder)
- ระบบคำนวณราคา

## New Enhanced Features (Phase 2-3)
- ระบบตรวจสอบความเป็นของแท้ (Serial Number Verification)
- ระบบสอนผู้ใช้วิธีตรวจสอบสเปค (Verification Education)
- ระบบแมตชิ่งตามสถานที่ (Location Matching)
- ระบบสำหรับคุณสมบัติผู้ขาย/ผู้ซื้อ (Seller/Buyer Checklist)
- ระบบการแลกเปลี่ยนปลอดภัย (Safe Transaction Flow)
- ระบบเปรียบเทียบสินค้า (Product Comparison)
- ระบบส่งข้อความระหว่างผู้ซื้อ-ผู้ขาย (Messaging)
- ระบบติดตามการทำธุรกรรม (Transaction Tracking)
- ระบบให้คะแนนและรีวิว (Rating & Review)
- ระบบแดชบอร์ดสำหรับผู้ใช้ (User Dashboard)
