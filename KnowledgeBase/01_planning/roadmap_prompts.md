# 📋 Prompts สำหรับใช้คู่กับ GenAI ในการพัฒนาโปรเจกต์ PC Builder Pro

คุณสามารถคัดลอกข้อความในกล่องด้านล่างของแต่ละเฟสไปใช้ป้อนให้กับ GenAI (เช่น Gemini, Claude, ChatGPT) เพื่อสั่งให้เขียนโค้ดและติดตั้งระบบแต่ละส่วนได้ทันทีครับ:

---

## 🔒 เฟส 1: ปรับปรุงความปลอดภัยฐานข้อมูลและการตรวจสอบข้อมูลขาเข้า (Security & DB Upgrade)

```markdown
กรุณาช่วยปรับปรุงระบบหลังบ้าน (Backend) ของโปรเจกต์ Node.js + Express ที่เดิมทีใช้งาน SQLite ให้เปลี่ยนเป็นระบบฐานข้อมูลสำหรับใช้งานจริง (Production) และเพิ่มความปลอดภัยในการทำธุรกรรมผ่านเงื่อนไขต่อไปนี้:

1. **สลับระบบฐานข้อมูลจาก SQLite เป็น PostgreSQL หรือ MySQL:**
   - แก้ไขไฟล์เชื่อมต่อฐานข้อมูลหลักและตัวรันเซิร์ฟเวอร์ ให้ดึงค่าคอนฟิก Host, User, Password, Port, Database มาจากไฟล์ `.env`
   - พัฒนา Schema และ Migration สำหรับสร้างตารางที่รองรับ (Users, Products, Parts, Orders, Chat Rooms, Wishlists, Addresses)
   - ปรับการเชื่อมคำสั่ง SQL ในคอนโทรลเลอร์ทั้งหมดให้อ่านค่าได้สมบูรณ์โดยตรง ไม่ต้องผ่าน Middleware แปลง SQL ระหว่างทาง

2. **ระบบป้องกันรหัสผ่านและโทเค็น (Session Security):**
   - อัปเดตกระบวนการเข้าสู่ระบบและสมัครสมาชิก ให้ส่งโทเค็น JWT ผ่านคุกกี้ที่เป็น HttpOnly และ Secure (Cookie-based auth) แทนการส่งผ่าน JSON response เพื่อความปลอดภัยสูงสุดจากการโจมตี XSS
   - ปรับแต่ง authMiddleware ให้อ่านโทเค็นจากคุกกี้ที่แนบมากับ HTTP Request อัตโนมัติ

3. **การตรวจสอบและสกัดกั้นข้อมูลขาเข้า (Input Validation):**
   - ติดตั้งและนำระบบ `express-validator` มาจัดการตรวจสอบฟอร์ม API ทุกตัว:
     * ข้อมูลสมัครสมาชิก: Username ต้องห้ามเป็นสัญลักษณ์แปลกปลอม, Email หรือ Phone ต้องมีรูปแบบถูกต้องและไม่ซ้ำกัน
     * การลงประกาศสินค้า: เช็กค่าตัวเลขราคาและสต็อกห้ามติดลบ, สกรีนการฉีดโค้ด (XSS Clean) สำหรับช่องอธิบายสินค้า
     * ระบบจองสินค้า: ตรวจสอบความถูกต้องของเลข ID และรูปแบบเบอร์โทรศัพท์ติดต่อ

กรุณาเขียนแนวทางโครงสร้างโค้ดและให้ทำรายการอัปเกรดไฟล์เหล่านี้ทีละส่วน พร้อมระบุคำสั่งในการเตรียมตารางฐานข้อมูลและติดตั้งไลบรารีที่จำเป็น
```

## 📷 เฟส 2: พัฒนาระบบอัปโหลดรูปภาพสินค้าและการจำลองระบบชำระเงินจริง (Media Upload & Payment)

```markdown
กรุณาช่วยพัฒนาระบบอัปโหลดไฟล์ภาพสินค้าและจำลองการจ่ายเงินจริงสำหรับโปรเจกต์ PC Builder Pro (Express + Node.js + Vanilla JS) โดยทำระบบดังนี้:

1. **ระบบอัปโหลดไฟล์ภาพสินค้าจริง (File Upload System):**
   - ใช้ไลบรารี `multer` ทำระบบรับไฟล์รูปภาพ (ประเภท png, jpeg, jpg เท่านั้น และจำกัดขนาดภาพไม่เกิน 5MB)
   - จัดการบันทึกภาพลงในโฟลเดอร์ฝั่งเซิร์ฟเวอร์ (เช่น `03_backend/uploads/products/`) พร้อมตั้งชื่อรูปใหม่เพื่อป้องกันการซ้ำซ้อน
   - ทำ API Endpoint สำหรับรับภาพการประกาศขายสินค้าและอัปเดตรูปร้านค้า/รูปโปรไฟล์ผู้ขาย
   - ปรับปรุงหน้า `sell-product.html` และ `profile.html` ให้ผู้ใช้กดเลือกไฟล์จากคอมพิวเตอร์และแสดงผลรูปตัวอย่าง (Preview) ได้ทันที

2. **ระบบการชำระเงินและตรวจสอบยอดโอน (Payment Integration Mockup):**
   - ปรับกระบวนการสั่งซื้อในใบจอง เมื่อสถานะเปลี่ยนจาก `pending` (รอเจรจา) ผู้ซื้อจะได้รหัสสำหรับยืนยันชำระเงิน
   - ทำระบบจำลองการสร้าง QR Code ชำระเงิน (PromptPay QR) โดยดึงข้อมูลยอดรวม (Total Price) มาคำนวณอัตโนมัติ เพื่อนำไปแสดงในหน้าแชตหรือหน้าประวัติสั่งซื้อ
   - เพิ่มระบบให้ผู้ซื้ออัปโหลดภาพหลักฐานการโอนเงิน (Slip Upload) จากนั้นสถานะของใบสั่งซื้อจะเปลี่ยนเป็น "รอผู้ขายตรวจสอบยอดเงิน" 
   - ฝั่งผู้ขายจะเห็นภาพสลิปใบโอนเงินเพื่อให้กดตรวจสอบเปรียบเทียบก่อนกดยืนยันยอดโอนสำเร็จ

กรุณาเขียนโค้ดส่วน API หลังบ้านสำหรับ Multer, ตัวแปร API สำหรับการเปลี่ยนสถานะออมทรัพย์ชำระเงิน และโค้ดส่วนหน้าบ้านในการสร้าง Element อัปโหลดและแสดงผลรูปภาพ
```

## ⚡ เฟส 3: ปรับปรุงระบบแชตให้เป็นแบบ Real-time ด้วย WebSockets (Real-time Communication)

```markdown
กรุณาปรับปรุงระบบคุยต่อรองราคาสินค้าและการเปลี่ยนสถานะใบสั่งจองของโปรเจกต์ PC Builder Pro จากปัจจุบันที่ใช้วิธี API Polling (ยิงถามเซิร์ฟเวอร์ทุก 3 วินาที) ให้เป็นระบบ Real-time ด้วย WebSockets เต็มรูปแบบ:

1. **การติดตั้งและตั้งค่าฝั่งหลังบ้าน (Backend WebSockets):**
   - ติดตั้งและติดตั้งไลบรารี `socket.io` เข้ากับ Express Server ในไฟล์ `server.js`
   - พัฒนาโมดูล Socket Manager ทำหน้าที่ควบคุมการทำงานของ Socket Connection
   - เมื่อผู้ใช้ทำการเปิดหน้าแชต ให้จับพวกเขาเข้าไปอยู่ใน Room ตาม ID ของห้องแชตคุยจองซื้อขาย (`chat_room_id`)
   - ระบบสลับข้อความแชต: เมื่อมีการบันทึกข้อความลงดาต้าเบส ให้ยิงอีเวนต์ `send_message` นำส่งข้อความไปยังคนในห้องตรงเวลานั้นทันที
   - ระบบอัปเดตสถานะดีลซื้อขาย: เมื่อผู้ขายกดยืนยันการโอน หรือระบุเลขพัสดุ ให้ยิงอีเวนต์ `update_order_status` เพื่อให้อีกฝั่งเปลี่ยนปุ่มเปลี่ยนหน้าจอได้ทันทีโดยไม่ต้องรีโหลดหน้าเว็บ

2. **การอัปเดตฝั่งหน้าบ้าน (Frontend WebSockets Integration):**
   - ติดตั้งโค้ดเชื่อมต่อ Socket.io Client ในไฟล์ `04_frontend/js/app.js` และหน้า `04_frontend/inbox.html`
   - เขียนลอจิกจัดการเปลี่ยนสถานะกล่องจดหมาย, อัปเดตยอดแจ้งเตือนข้อความที่ยังไม่ได้อ่าน (Unread Count) ทันทีบนเมนูบาร์ด้านบน
   - ถอดลอจิก `setInterval` โพลล์ดึงข้อมูล API ทิ้งทั้งหมดเพื่อประหยัดทรัพยากรผู้ใช้งานและเซิร์ฟเวอร์

กรุณาเขียนโค้ดพร้อมคำอธิบายสำหรับการเซ็ตระบบฝั่ง Express.js และวิธีการเขียน Javascript ฝั่งหน้าบ้านเชื่อมรับ-ส่งอีเวนต์ Socket
```

## 🧠 เฟส 4: เพิ่มความอัจฉริยะระบบประเมินราคาและการจัดสเปกคอม (Intelligent Compatibility & Offers)

```markdown
กรุณาช่วยพัฒนาระบบประเมินสเปกและแนะนำราคาเสนอขายที่ดีที่สุด (Smart Assistant & Advanced Rules) ในส่วนการจัดสเปกคอมพิวเตอร์และเชื่อมโยงกับ Marketplace:

1. **การคำนวณข้อจำกัดฮาร์ดแวร์แบบก้าวหน้า (Advanced Hardware Compatibility):**
   - ขยายระบบตรวจสอบความเข้ากันได้ฮาร์ดแวร์ใน `compatibilityService.js`:
     * เพิ่มการเช็กขนาดบอร์ด (Form Factor) ให้บอร์ดขนาดใหญ่ (เช่น ATX) ใส่เคสขนาดเล็กไม่ได้ (เช่น Mini-ITX) แต่บอร์ดเล็กใส่เคสใหญ่ได้
     * ตรวจสอบ RAM clearance: หากผู้ใช้เลือกพัดลมระบายความร้อนขนาดใหญ่และใช้แรมทรงสูง (RGB/Heatsink สูง) ให้แจ้งเตือนความเสี่ยง
     * ตรวจสอบหัวต่อไฟเลีย้ง (EPS 12V / PCIE Cable connectors) จาก PSU เทียบกับชิ้นส่วนเมนบอร์ดและการ์ดจอ

2. **ระบบจับคู่ Marketplace ดีที่สุดอัตโนมัติ (Marketplace Direct Recommendations):**
   - ในหน้าจัดสเปกคอม (`builder.html`) เมื่อผู้ใช้เลือกชิ้นส่วนหลักใดชิ้นหนึ่ง (เช่น CPU Intel i5-12400F) ให้ระบบดึงข้อมูลจากตาราง `products` มาประเมินหาประกาศขายในตลาดที่มีราคา "ถูกที่สุด" และอยู่ในสถานะ "พร้อมขาย (Active)"
   - แสดงกล่องแนะนำในหน้าจัดสเปกทันที เช่น "พบสินค้านี้ในตลาดมือสองสภาพดี ราคาเพียง ฿4,200 (ประหยัดไป ฿1,290) [คลิกดูข้อเสนอ]" เพื่อดึงดูดความต้องการของผู้ใช้ให้เกิดการทำธุรกรรมจริง

กรุณาเขียนลอจิกเปรียบเทียบขนาด ความสูง และสายไฟที่ละเอียดเพิ่มเติมในฝั่งหลังบ้าน พร้อมโค้ดแสดงผลข้อเสนอราคาตลาดมือสองบน UI หน้าจัดสเปกคอมพิวเตอร์
```
