# UI/UX Mockup Description

## Home Page
- Header: Logo, Search Bar, Navigation Menu, Login/Register Button
- Hero Section: ยินดีต้อนรับ + ปุ่ม "ดูสินค้า"
- Featured Products: แสดงสินค้ายอดนิยม 6-8 รายการ
- Categories: ไอคอน CPU, GPU, Motherboard, RAM, Storage
- Footer: Contact, About, Privacy Policy

## Product List Page
- Left Sidebar: Filter by Category, Price Range, Search Bar
- Main Content: Grid layout สินค้า (3-4 column)
- Pagination: หน้า 1, 2, 3... ด้านล่าง
- Sort: ราคา (น้อยไปมาก, มากไปน้อย), ใหม่สุด, ยอดนิยม

## Product Detail Page
- Product Image (Zoom feature)
- Product Info: ชื่อ, ราคา, สเปค, สถานะสินค้า
- Seller Info: ชื่อผู้ขาย, Rating, Contact
- Buttons: "ซื้อเลย", "แชท", "Add to Wishlist"
- Related Products: สินค้าอื่นจากผู้ขายเดียวกัน

## Login / Register Page
- Form: Email/Username, Password, Confirm Password
- Social Login: (ตัวเลือก) Google, Facebook
- Validation: แสดง error message ถ้ามีปัญหา

## Sell Product Page
- Form: ชื่อสินค้า, ราคา, หมวดหมู่, รายละเอียด
- Upload Image: Drag & Drop / Browse
- Preview: ดูตัวอย่างสินค้า
- Button: "ลงขาย"

## PC Builder Page
- Left Sidebar: เลือกอะไหล่ (CPU, GPU, Motherboard, RAM, Storage)
- Main Content: แสดง Build ที่เลือก
- Right Sidebar: แสดงราคาและสเปครวม
- Buttons: "ยืนยัน", "รีเซ็ต", "บันทึก Build"

## Navigation
- Responsive Design: Mobile, Tablet, Desktop
- Hamburger Menu: สำหรับ Mobile
- Breadcrumb: Home > Products > Product Name
