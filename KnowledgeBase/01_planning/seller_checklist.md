# Seller Pre-Listing Checklist

ขั้นตอนที่ผู้ขายต้องทำ **ก่อนลงขาย**:

## Step 1: Verify Authenticity (ตรวจสอบของแท้)

### Serial Number Check
- [ ] บันทึกเลข Serial Number / IMEI
- [ ] ถ่ายรูป Serial Number ชัดเจน
- [ ] ตรวจสอบตำแหน่ง Serial Number ตรงกับรุ่นไหม
- [ ] โปรแกรมตรวจสอบ (ถ้ามี)

### Physical Check
- [ ] ตรวจสอบแบรนด์ลโก้/สัญลักษณ์
- [ ] ตรวจสอบคุณภาพการพิมพ์/แกะสลัก
- [ ] ตรวจสอบซีลของเดิม (ถ้ามี)
- [ ] ถ่ายรูปลักษณ์ภายนอกมุมต่างๆ

### Packaging & Accessories
- [ ] มีกล่องต้นฉบับไหม
- [ ] มีอุปกรณ์อะไรบ้างครบไหม
- [ ] สภาพกล่องเป็นไงบ้าง

---

## Step 2: Test Functionality (ทดสอบว่าใช้ได้)

### Power & Boot
- [ ] เปิดเครื่องได้ไหม
- [ ] ตั้งแต่ไหนเมื่อกด Power
- [ ] เข้า OS ได้ไหม

### Hardware Test
- [ ] CPU/GPU ใช้ได้ปกติไหม (Run diagnostics)
- [ ] RAM ครบไหม (Check RAM capacity)
- [ ] Storage ใช้ได้ไหม (Check free space)
- [ ] ไม่มี Bad Sectors ไหม

### Ports & Connections
- [ ] USB ทำงานปกติไหม
- [ ] Audio/Headphone Jack ได้ยินเสียงไหม
- [ ] Display/Monitor หรือ Screen ชัดไหม
- [ ] Keyboard/Trackpad ตอบสนองปกติไหม

### Battery (Laptop/Notebook/Phone)
- [ ] ชาร์จได้ไหม
- [ ] ใช้งานได้นานเท่าไหร่ (Estimate)
- [ ] Battery health ดีไหม

---

## Step 3: Document Everything (จัดเอกสาร)

### Photos Required
- [ ] ภาพรวมหน้าและหลัง (4 มุม)
- [ ] ภาพ Serial Number
- [ ] ภาพหน้าจอ (BIOS/System Info)
- [ ] ภาพสภาพเบิ้มหรือเสียหาย (ถ้ามี)

### Test Results
- [ ] Screenshot HW Info / System Information
- [ ] Screenshot Diagnostics Results
- [ ] Screenshot Battery Report (ถ้ามี)

### Condition Description
- [ ] สภาพภายนอก: ดี/ปกติ/มีรอยใช้งาน/มีรอยเสียหาย
- [ ] สภาพภายใน: ไม่ได้เปิด/ง่ายกว่า/เคยซ่อมแซม
- [ ] รายละเอียด Problem/Issue/Damage ถ้ามี
- [ ] ยังเหลืออุปกรณ์อะไรบ้าง

---

## Seller Verification Status

ผู้ขายจะได้ badge ตามว่า:
- 🟢 **Verified**: ผ่านการตรวจสอบทั้ง 3 ขั้นตอน
- 🟡 **Partial**: ผ่านบางขั้นตอน
- 🔵 **New Seller**: ยังไม่มีเอกสาร
