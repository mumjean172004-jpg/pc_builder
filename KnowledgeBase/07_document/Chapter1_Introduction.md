# คู่มือการจัดรูปแบบหน้ากระดาษใน Microsoft Word (สำหรับโครงงาน/วิทยานิพนธ์)

ก่อนคัดลอกเนื้อหาบทที่ 1 ไปใช้งานใน Microsoft Word ขอแนะนำให้ตั้งค่าหน้ากระดาษและฟอนต์ตามมาตรฐานการจัดทำเล่มโครงงานวิชาการของมหาวิทยาลัยดังนี้:

1. **การตั้งค่าระยะขอบ (Margins):**
   * **ขอบบน (Top):** 1.5 นิ้ว (3.81 ซม.) — *เนื่องจากเป็นหน้าเริ่มต้นของบท* (หน้าทั่วไปใช้ 1.0 นิ้ว)
   * **ขอบล่าง (Bottom):** 1.0 นิ้ว (2.54 ซม.)
   * **ขอบซ้าย (Left):** 1.5 นิ้ว (3.81 ซม.) — *เผื่อพื้นที่สำหรับเข้าเล่ม*
   * **ขอบขวา (Right):** 1.0 นิ้ว (2.54 ซม.)
2. **รูปแบบตัวอักษร (Font):**
   * ใช้ฟอนต์มาตรฐาน: **TH Sarabun New** หรือ **TH Sarabun PSK**
   * **ชื่อบท (เช่น บทที่ 1 บทนำ):** ขนาด **20pt ตัวหนา** จัดกึ่งกลางหน้ากระดาษ
   * **หัวข้อย่อยหลัก (เช่น 1.1, 1.2):** ขนาด **18pt ตัวหนา** จัดชิดซ้าย
   * **หัวข้อย่อยรอง (เช่น 1.3.1):** ขนาด **16pt ตัวหนา** จัดชิดซ้าย (หรือเยื้องตามความเหมาะสม)
   * **เนื้อหาปกติ (Body Text):** ขนาด **16pt ตัวปกติ** จัดแนวแบบ "กระจายแบบไทย" (Thai Distributed) หรือ "จัดชิดขอบ" (Justify) เพื่อความเรียบร้อย
3. **การตั้งค่าระยะย่อหน้าและบรรทัด:**
   * **ย่อหน้าเริ่มต้น (First Line Indent):** เยื้องขวา **1.25 เซนติเมตร (หรือ 0.5 นิ้ว)**
   * **ระยะห่างบรรทัด (Line Spacing):** 1.0 หรือ 1.15 เท่า
   * **ระยะห่างระหว่างย่อหน้า (Before/After):** 0pt ทั้งคู่ (ใช้การกด Enter แยก หรือตั้งค่า After เป็น 6pt)

### 1.1 ที่มาและความสำคัญของปัญหา
ในทศวรรษที่ผ่านมา เทคโนโลยีด้านฮาร์ดแวร์คอมพิวเตอร์ (Computer Hardware) มีอัตราการเติบโตและพัฒนาอย่างก้าวกระโดด ส่งผลให้ชิ้นส่วนอุปกรณ์ภายในคอมพิวเตอร์ เช่น หน่วยประมวลผลกลาง (CPU) หน่วยประมวลผลกราฟิก (GPU) และหน่วยความจำเข้าถึงโดยสุ่ม (RAM) มีประสิทธิภาพการประเมินผลที่สูงขึ้นเป็นทวีคูณ ในขณะที่ต้นทุนการผลิตกลับลดต่ำลง ส่งผลให้พฤติกรรมของผู้บริโภคเปลี่ยนจากการซื้อคอมพิวเตอร์สำเร็จรูป (Brand-name PC) มาเป็นการจัดสเปกและประกอบคอมพิวเตอร์ด้วยตนเอง (Custom DIY PC Building) เนื่องจากผู้ใช้งานสามารถเลือกชิ้นส่วนที่ตรงตามวัตถุประสงค์การใช้งานและควบคุมงบประมาณได้อย่างมีประสิทธิภาพสูงสุด ไม่ว่าจะเป็นการนำไปใช้ในงานด้านความบันเทิงและการเล่นเกม (Gaming) งานคำนวณขั้นสูง งานประมวลผลโมเดลปัญญาประดิษฐ์ หรือการสร้างสรรค์สื่อมัลติมีเดีย (Content Creation)

อย่างไรก็ดี แม้ว่าความนิยมในการประกอบคอมพิวเตอร์ด้วยตนเองจะเพิ่มขึ้นอย่างต่อเนื่อง แต่กลุ่มผู้บริโภคทั่วไปรวมถึงผู้เริ่มต้นศึกษาระบบคอมพิวเตอร์ยังคงต้องเผชิญกับอุปสรรคสำคัญที่เรียกว่า **"ปัญหาความไม่เข้ากันของอุปกรณ์ฮาร์ดแวร์ (Hardware Incompatibility)"** เนื่องจากผู้ผลิตชิ้นส่วนฮาร์ดแวร์แต่ละรายมีมาตรฐานและเทคโนโลยีเฉพาะตัวที่ไม่เป็นเอกภาพ ส่งผลให้การทำงานร่วมกันของอุปกรณ์มีเงื่อนไขและข้อจำกัดที่ซับซ้อน เช่น ความเข้ากันได้ของขั้วต่อตัวประมวลผลกลางและเมนบอร์ด (CPU and Motherboard Sockets) ชนิดและจำนวนช่องเสียบแรม (RAM Memory Format and Slot Limits) ขนาดมิติทางกายภาพความกว้างยาวของกล่องบรรจุอุปกรณ์ที่จำกัดพื้นที่ความกว้างของการ์ดจอและความสูงของระบบระบายความร้อน (GPU and CPU Cooler Clearance Dimensions) ตลอดจนการคำนวณปริมาณการจ่ายพลังงานไฟฟ้าของระบบโดยรวมที่ต้องสอดคล้องกับพาวเวอร์ซัพพลาย (Power Supply Unit Compatibility) การเลือกซื้อชิ้นส่วนฮาร์ดแวร์ที่ผิดพลาดส่งผลให้เกิดความสูญเสียทางเวลาและงบประมาณอย่างหลีกเลี่ยงไม่ได้

นอกจากนี้ ตลาดชิ้นส่วนอุปกรณ์คอมพิวเตอร์ยังมีพฤติกรรมการเปลี่ยนถ่ายฮาร์ดแวร์ที่รวดเร็ว ผู้ใช้งานมักทำการอัปเกรดชิ้นส่วนเฉพาะจุด (เช่น การเปลี่ยนการ์ดจอหรือซีพียูใหม่) ทำให้เกิดปริมาณชิ้นส่วนอะไหล่มือสองในระบบสะสมอยู่เป็นจำนวนมาก ตลาดซื้อขายอะไหล่คอมพิวเตอร์มือสองในลักษณะผู้บริโภคถึงผู้บริโภค (Consumer-to-Consumer: C2C) จึงขยายตัวอย่างรวดเร็ว อย่างไรก็ตาม การซื้อขายบนแพลตฟอร์มโซเชียลมีเดียหรือเว็บบอร์ดทั่วไปมักประสบ **"ปัญหากลโกงและการทุจริตทางการค้า (Marketplace Frauds)"** ที่ทวีความรุนแรงมากขึ้น อาทิเช่น ผู้ขายสินค้าหลอกลวงตั้งราคาเสนอขายที่ต่ำกว่าราคากลางในระดับผิดปกติเพื่อดึงดูดเหยื่อให้โอนเงินมัดจำ (Bait-and-Switch Tactics) การนำหมายเลขซีเรียลนัมเบอร์ (Serial Number) ของผลิตภัณฑ์หรือภาพถ่ายของผู้อื่นมาลงประกาศซ้ำซ้อนเพื่อหลอกขาย ตลอดจนความล้าช้าและความไม่ปลอดภัยในการเจรจาซื้อขายและการส่งหลักฐานสลิปโอนเงินชำระค่าสินค้าที่ตรวจสอบได้ยาก

จากสภาพปัญหาดังกล่าว คณะผู้พัฒนาจึงเล็งเห็นความสำคัญในการพัฒนาเว็บแอปพลิเคชันภายใต้โครงการ **PC Builder Pro (แพลตฟอร์มจัดสเปกคอมพิวเตอร์ออนไลน์ และตลาดกลางซื้อขายชิ้นส่วนอะไหล่มือสอง C2C)** เพื่อแก้ปัญหาอย่างเป็นรูปธรรม ระบบที่พัฒนาขึ้นจะประกอบไปด้วย "ตัวคำนวณตรวจจับความเข้ากันได้อัจฉริยะ (Compatibility Checking Service)" ที่ประเมินผลเชิงลึกทั้งสเปกกายภาพและไฟฟ้าเพื่อป้องกันความผิดพลาดในการเลือกประกอบเครื่อง ควบคู่กับ "ระบบตลาดกลางที่มีกลไกกรองบัญชีทุจริต (Anti-Fraud Guard System)" ที่ประเมินคะแนนความน่าสงสัยจากประวัติราคากลางและข้อมูลซีเรียลนัมเบอร์ พร้อมด้วย "ระบบแชตและธุรกรรมการสั่งจองเรียลไทม์ (Real-time Socket Chat)" เพื่อสร้างมาตรฐานใหม่ของความปลอดภัย ความน่าเชื่อถือ และความสะดวกสบายในการจัดสเปกและซื้อขายชิ้นส่วนคอมพิวเตอร์ในสังคมออนไลน์

### 1.2 วัตถุประสงค์ของโครงงาน
ในการดำเนินงานพัฒนาระบบ คณะผู้พัฒนาได้กำหนดวัตถุประสงค์หลักไว้ดังนี้:
1. เพื่อวิเคราะห์ ออกแบบ และพัฒนาเว็บแอปพลิเคชันจัดสเปกคอมพิวเตอร์ออนไลน์ (PC Builder Pro) ที่มีหน้าจอการเชื่อมต่อผู้ใช้งานแบบพรีเมียมล้ำสมัยและตอบสนองได้ทุกอุปกรณ์
2. เพื่อพัฒนาตัวตรวจสอบความเข้ากันได้ของอุปกรณ์คอมพิวเตอร์ (Hardware Compatibility Verification Engine) โดยอาศัยตรรกะแบบกฎเกณฑ์ (Rule-based constraints) ครอบคลุมคุณลักษณะทางกายภาพ พลังงานไฟฟ้า และชิปเซต
3. เพื่อวิเคราะห์และพัฒนาระบบคัดกรองสินค้าทุจริตในตลาดสินค้าไอทีมือสอง (Anti-Fraud Listing Classifier) ที่สามารถคำนวณคะแนนความเสี่ยง (Suspicious Score) ได้โดยอัตโนมัติก่อนลงประกาศ
4. เพื่อพัฒนาสถาปัตยกรรมห้องสนทนาเจรจาต่อรองและการชำระเงินโอนซื้อขายชิ้นส่วนมือสองแบบเรียลไทม์ (WebSockets Chat Integration and Order Booking System) ที่มีระบบคืนสินค้าอัตโนมัติ (Stock Rollback) เพื่อความโปร่งใสและปลอดภัยสูง

### 1.3 ขอบเขตของโครงงาน
คณะผู้พัฒนาได้กำหนดขอบเขตและหน้าที่การทำงานของเว็บแอปพลิเคชัน PC Builder Pro แยกตามความรับผิดชอบและบทบาทผู้ใช้งานดังต่อไปนี้:

#### 1.3.1 ขอบเขตการทำงานของระบบฝั่งผู้ใช้งานทั่วไป (Member Area)
1. **ระบบสมัครสมาชิกและยืนยันตัวตน (Authentication System):**
   * สมัครสมาชิกระบบโดยกรอกชื่อผู้ใช้ (Username) อีเมล (Email) และรหัสผ่าน (Password)
   * เข้าสู่ระบบด้วยอีเมลและรหัสผ่าน โดยระบบใช้กลไกจัดเก็บโทเค็นความปลอดภัย JWT Session ผ่าน HttpOnly, Secure, SameSite=Lax Cookie
   * สามารถเรียกดูข้อมูลโปรไฟล์ส่วนตัว อัปเดตรูปภาพประจำตัว (Avatar) และสลับบทบาทการใช้งานเป็นผู้ซื้อ (Buyer) หรือผู้ขาย (Seller)
2. **ระบบจัดสเปกคอมพิวเตอร์อัจฉริยะ (Smart PC Builder):**
   * เลือกชิ้นส่วนเข้าชุดจัดสเปกประกอบด้วย 7 หมวดหมู่หลัก ได้แก่ CPU, Motherboard, GPU, RAM, Storage, PSU และ Case
   * แสดงค่าราคารวมของชิ้นส่วนที่เลือกแบบเรียลไทม์
   * ระบบประเมินผลความเข้ากันได้แบบอัตโนมัติ โดยระบุคำแจ้งเตือน (Warnings) และข้อผิดพลาดระดับวิกฤต (Errors) ทันทีที่มีการเพิ่มหรือเปลี่ยนอุปกรณ์
   * สามารถบันทึกชุดสเปก (Save Build) ไปยังบัญชีส่วนตัว พร้อมระบุชื่อชุด คำอธิบาย และสิทธิ์การเข้าถึง (ส่วนตัว หรือ สาธารณะ)
   * แสดงความคิดเห็น (Comment) และกดไลก์ (Like) ให้กับชุดจัดสเปกที่เป็นสาธารณะของผู้ใช้รายอื่น
3. **ระบบตลาดซื้อขายอะไหล่มือสอง (C2C Marketplace):**
   * ค้นหาสินค้ามือสองด้วยคีย์เวิร์ด และกรองตามหมวดหมู่ชิ้นส่วนหรือระดับสภาพสินค้าได้
   * ลงประกาศขายชิ้นส่วนมือสอง (ต้องการล็อกอิน) โดยระบุข้อมูลแคตตาล็อกอ้างอิง สภาพสินค้า (`new`, `used_90`, `used_80`, `used_70`) ประกันคงเหลือ ราคา ซีเรียลนัมเบอร์ คำอธิบายประกอบ และสามารถอัปโหลดรูปภาพสินค้าได้สูงสุด 10 รูป (กรณีสินค้ามือสองบังคับอัปโหลดภาพอย่างน้อย 3 รูป)
   * ผู้ขายสามารถตั้งค่าบัญชีธนาคาร ชื่อร้านค้า และเบอร์ติดต่อสำหรับรับเงินโอนได้ที่หน้าโปรไฟล์
4. **ระบบการสั่งจองและห้องสนทนาเรียลไทม์ (C2C Order Negotiation & Chats):**
   * ผู้ซื้อสามารถกดจองสินค้า (Book) จากหน้าประกาศขาย โดยระบบจะทำการปิดสต็อกชั่วคราว ดึงข้อมูลที่อยู่จัดส่งเริ่มต้นและเบอร์ติดต่อ และสร้างห้องแชตคุยเฉพาะระหว่างผู้ซื้อและผู้ขายคนดังกล่าวโดยอัตโนมัติ
   * หน้าต่างห้องสนทนารองรับการส่งข้อความโต้ตอบ และระบบจะส่งข้อความแจ้งสถานะอัตโนมัติ (System message) เมื่อเกิดการเปลี่ยนแปลงในใบสั่งซื้อ
   * ผู้ซื้อสามารถแนบภาพถ่ายสลิปเงินโอนผ่านระบบเพื่อส่งหลักฐานการชำระเงิน
   * ผู้ขายสามารถกดอนุมัติยอดโอนชำระเงินเงิน (Approve Slip) หรือปฏิเสธเพื่อล้างรูปสลิปให้ผู้ซื้อส่งใหม่
   * ผู้ขายสามารถระบุข้อมูลการจัดส่งและหมายเลขติดตามพัสดุ (Tracking Number)
   * ผู้ซื้อสามารถกดปุ่มยืนยันการรับสินค้าและสิ้นสุดรายการธุรกรรม (Complete Order)
   * ทั้งผู้ซื้อและผู้ขายสามารถกดยกเลิกรายการสั่งจอง (Cancel Booking) ได้ตลอดเวลาก่อนการยืนยันยอดเงิน โดยหลังบ้านจะทำการ Rollback คืนสิทธิ์สินค้ากลับตลาดเพื่อความปลอดภัยโดยอัตโนมัติ

#### 1.3.2 ขอบเขตการทำงานของระบบฝั่งผู้ดูแลระบบ (Admin Panel)
1. **ระบบตรวจสอบและอนุมัติสินค้าที่น่าสงสัย (Moderation Queue):**
   * แสดงคิวสินค้าที่มีคะแนน Suspicious Score สูงกว่าหรือเท่ากับ 70 คะแนน ซึ่งระบบบล็อกไม่ให้แสดงผลในตลาดซื้อขายทั่วไป
   * แสดงเหตุผลที่ระบบปักธงความเสี่ยง (Flags) เช่น ราคากลางตกเกณฑ์สภาพ หรือซีเรียลนัมเบอร์ซ้ำซ้อน
   * ผู้ดูแลระบบสามารถคลิกตรวจสอบภาพถ่าย รายละเอียด และกดยืนยันอนุมัติ (Approve) หรือปฏิเสธประกาศขาย (Reject) ได้
2. **ระบบการบันทึกประวัติการกระทำของแอดมิน (Admin Activity Logs):**
   * บันทึกรายการดำเนินการที่สำคัญของแอดมินทุกคน เช่น รหัสแอดมิน การกระทำที่กระทำ (เช่น การอนุมัติสินค้า หรือระงับบัญชี) รายละเอียดการกระทำ และวันเวลา เพื่อความปลอดภัยสูงสุด

#### 1.3.3 ขอบเขตการประมวลผลและการคำนวณทางเทคนิค (Core Engines)
1. **ระบบคัดกรองความเข้ากันได้ฮาร์ดแวร์ (Compatibility Engine):**
   * ตรวจสอบว่า Socket ของ CPU และ Motherboard ตรงกันตรงอักษร
   * ตรวจสอบระดับการรองรับชิปเซตเมนบอร์ดกับตัวประมวลผลกลาง
   * ตรวจสอบชนิดประเภทแรม (DDR) ว่าตรงกับเมนบอร์ด
   * ตรวจสอบความจุแรมสูงสุดและจำนวนช่องสล็อตที่เมนบอร์ดรองรับไม่ให้เกินเกณฑ์
   * ตรวจสอบความยาวการ์ดจอกับระยะพื้นที่สูงสุดของเคส (มีคำเตือนเมื่อระยะห่างเหลือต่ำกว่า 10%)
   * ตรวจสอบความสูงของระบบระบายความร้อนด้วยลมกับขีดจำกัดความกว้างเคส
   * ตรวจสอบความสอดคล้องของขนาดหม้อน้ำ (AIO Radiator) กับช่องยึดพัดลมที่เคสรองรับ
   * ตรวจสอบขนาดของเมนบอร์ด (Form Factor) ว่ามีขนาดใหญ่เกินเคสคอมพิวเตอร์หรือไม่
   * คำนวณอัตราความต้องการพลังงานไฟฟ้ารวมของระบบ $TDP_{Est}$ และตรวจสอบว่าสูงกว่ากำลังวัตต์ของพาวเวอร์ซัพพลาย (PSU Wattage) หรือไม่ พร้อมสร้างข้อความแจ้งเตือนหากพาวเวอร์ซัพพลายมีกำลังวัตต์ต่ำกว่าเกณฑ์ความปลอดภัย $TDP_{Est} \times 1.25$
2. **ระบบตรวจวัดพฤติกรรมการทุจริตของประกาศขาย (Anti-Fraud Screening Engine):**
   * ประเมินหาเกณฑ์ราคากลางขั้นต่ำที่เป็นไปได้ (Price Floor Limit) ตามราคา MSRP แคตตาล็อกและคุณภาพสภาพสินค้า
   * ตรวจสอบค่าซีเรียลนัมเบอร์ในฐานข้อมูลไม่ให้อ้างอิงซ้ำซ้อนกับผลิตภัณฑ์อื่นที่ยังไม่ได้จำหน่ายสำเร็จ

### 1.4 ประโยชน์ที่คาดว่าจะได้รับ
1. ผู้ใช้งานทั่วไปมีเครื่องมือที่มีความแม่นยำสูงในการทดลองจัดสเปกประกอบคอมพิวเตอร์ด้วยตนเอง ช่วยลดความเสี่ยงจากการซื้ออุปกรณ์ผิดรุ่นที่ใช้งานร่วมกันไม่ได้
2. ผู้บริโภคในกลุ่มตลาด C2C สามารถค้นหาและสั่งซื้อชิ้นส่วนอะไหล่คอมพิวเตอร์มือสองได้อย่างมั่นใจมากขึ้น ด้วยความปลอดภัยผ่านระบบ Anti-Fraud Scans
3. อัตราการหลอกลวงหรือการตั้งกระทู้ขายสินค้าหลอกลวงลดลงอย่างเห็นได้ชัดผ่านการกลั่นกรองอัตโนมัติและคิวรีวิวของแอดมินก่อนสินค้าแสดงผลจริง
4. สภาพแวดล้อมการต่อรองเจรจาซื้อขายชิ้นส่วนคอมพิวเตอร์เป็นไปอย่างสะดวกรวดเร็วและเป็นระบบ มีห้องแชตโต้ตอบและอัปเดตสถานะแบบเรียลไทม์ที่ควบคุมสถานะสต็อกสินค้าอย่างรัดกุม
5. คณะผู้พัฒนาได้รับความเข้าใจเชิงลึกเกี่ยวกับสถาปัตยกรรม WebSockets การทำงานของ SQL Transaction Rollback และสัญวิทยาการออกแบบเว็บไซด์แบบ Glassmorphism

### 1.5 วิธีการดำเนินโครงงาน
การดำเนินงานโครงการ PC Builder Pro ได้ประยุกต์ใช้กระบวนการทางวิศวกรรมซอฟต์แวร์ตามแบบจำลองความปลอดภัยและการพัฒนาระบบ SDLC แบ่งเป็น 6 เฟสดังรายละเอียดกิจกรรมต่อไปนี้:

1. **การวิเคราะห์และเก็บข้อมูลความต้องการ (Requirements Phase):**
   * ค้นหาและรวบรวมข้อจำกัดความเข้ากันได้ของชิ้นส่วนอุปกรณ์จากเว็บไซต์แบรนด์ชั้นนำ (เช่น Intel, AMD, NVIDIA, ASUS, GIGABYTE)
   * ศึกษาพฤติกรรมและความต้องการของนักจัดสเปกคอมพิวเตอร์และผู้ซื้อขายอะไหล่มือสอง เพื่อระบุขอบเขตการแก้ไขปัญหากลโกง
2. **การวิเคราะห์และออกแบบระบบ (Analysis and Design Phase):**
   * ออกแบบรูปแบบการจัดวางตารางในฐานข้อมูล (MySQL Schema Design) กำหนดประเภทตัวแปรให้เหมาะสม ดักจับคีย์นอก (Foreign Keys) และกำหนด Constraints
   * ออกแบบสถาปัตยกรรมระบบ (System Architecture) กำหนดโครงสร้างการสื่อสารแบบ REST API และ Real-time WebSockets
   * วาดพิมพ์เขียวหน้าต่างเว็บแอปพลิเคชัน (Wireframe UI Layouts) ในสไตล์ธีมมืดเรืองแสง
3. **การพัฒนาระบบส่วนหลังบ้าน (Backend Engine Development):**
   * ติดตั้ง Node.js สร้างไฟล์แอปพลิเคชัน Express.js
   * พัฒนาระบบยืนยันตัวตนและการเข้าถึงแบบ Cookie-based Session
   * เขียนชุดโปรแกรมคำนวณหาความเข้ากันได้ (Compatibility Service) และตรรกะประเมินราคาตามสภาพของชิ้นส่วน (Anti-Fraud Controller)
   * บูรณาการระบบ Socket.io ควบคุมเซสชันแชตและการรับส่งข้อมูลสด
4. **การพัฒนาระบบส่วนหน้าบ้าน (Frontend UI Development):**
   * พัฒนาโครงสร้าง HTML ในแต่ละหน้าจอแสดงผล
   * พัฒนา CSS จัดสไตล์ความสวยงามสไตล์ Glassmorphism (โปร่งแสง หรูหรา ขอบเงาบางเบา และการเบลอหลัง) พร้อมตอบสนองต่อขนาดหน้าจอ
   * พัฒนาไฟล์ควบคุม JavaScript (Vanilla JS) สำหรับเชื่อมต่อข้อมูลกับ REST API หลังบ้าน จัดการตัวควบคุมการแสดงผล (DOM Control) และเชื่อมโยง WebSockets
5. **การทดสอบและการแก้ไขระบบ (Testing & Validation Phase):**
   * ดำเนินการทดสอบระบบ (Integration Testing) ในระดับสถานการณ์ผู้ใช้ต่างๆ (User Scenarios) เช่น การพยายามจัดสเปกคอมพิวเตอร์ที่ชิ้นส่วนขัดแย้งกัน
   * ทดสอบระบบสั่งจองและตัดขายว่าทำงานถูกต้อง และทำการตรวจสอบ Transaction Rollback เมื่อยกเลิกออเดอร์
   * ทดสอบการลงขายสินค้าทุจริตเพื่อยืนยันว่าโพสต์ถูกซ่อนและส่งไปยังแอดมินจริง
6. **การส่งมอบงานและรายงานเอกสาร (Documentation Phase):**
   * จัดทำเอกสารและเล่มรายงานโครงงานฉบับสมบูรณ์ (บทที่ 1 ถึงบทที่ 5) เพื่ออธิบายขั้นตอนการทำงานและทฤษฎีที่เกี่ยวข้องโดยละเอียด

### 1.6 เครื่องมือและภาษาที่ใช้ในการพัฒนา
ในการจัดทำโครงงานวิศวกรรมซอฟต์แวร์ คณะผู้พัฒนาได้เลือกใช้เทคโนโลยีและระบบที่ทันสมัยดังนี้:

#### 1.6.1 เครื่องมือด้านฮาร์ดแวร์ (Hardware Tools)
* เครื่องคอมพิวเตอร์สำหรับพัฒนาระบบปฏิบัติการ Windows 10/11 หน่วยประมวลผลกลางสถาปัตยกรรม x64 หน่วยความจำแรมขั้นต่ำ 16GB
* อุปกรณ์สมาร์ทโฟนระบบปฏิบัติการ iOS และ Android สำหรับทดสอบความเข้ากันได้ของ Responsive UI หน้าจออุปกรณ์เคลื่อนที่

#### 1.6.2 เครื่องมือด้านซอฟต์แวร์และการเขียนรหัสโปรแกรม (Software Tools)
* **Visual Studio Code:** โปรแกรมหลักสำหรับแก้ไขรหัสต้นฉบับ (Code Editor)
* **MySQL Community Server (Port 3306):** ระบบจัดการฐานข้อมูลบนเครื่องจำลองโลคอล
* **DBeaver / phpMyAdmin:** โปรแกรมบริหารจัดการและเขียนชุดคำสั่งคิวรี SQL
* **Git & GitHub:** ระบบควบคุมรุ่นซอฟต์แวร์ (Version Control System) สำหรับบันทึกความคืบหน้าของโค้ด
* **Google Chrome / Mozilla Firefox:** เว็บเบราว์เซอร์สำหรับทดสอบการแสดงผลและใช้โปรแกรม Inspect DevTools

#### 1.6.3 เครื่องมือและภาษาทางเทคโนโลยี (Development Tech Stack)
* **ภาษาฝั่งผู้รับบริการ (Frontend Languages):**
  * **HTML5:** ประกาศโครงสร้างองค์ประกอบหน้าเว็บและแบบฟอร์มรับส่งค่า
  * **CSS3:** ตกแต่งหน้ากากแสดงผล จัดโครงร่าง (Flexbox, Grid) และทำอนิเมชันขนาดเล็ก
  * **JavaScript (ECMAScript 6+):** ควบคุมตรรกะในเบราว์เซอร์ จัดการ JSON ข้อมูล และจัดการการดึงข้อมูล REST API ผ่าน fetch
* **เทคโนโลยีฝั่งผู้ให้บริการและเครือข่าย (Backend & Networking):**
  * **Node.js:** สภาพแวดล้อมรันจาวาสคริปต์ความเร็วสูงนอกเว็บเบราว์เซอร์
  * **Express.js:** โครงสร้างหลักบริหารจัดการ Web REST Routing
  * **Socket.io & Socket.io-client:** ระบบจัดการช่องเชื่อมต่อ WebSocket การสื่อสารสดเรียลไทม์
  * **bcrypt:** ไลบรารีความปลอดภัยแปลงแฮชรหัสผ่านของผู้ใช้ (Salt Rounds = 10)
  * **jsonwebtoken:** เครื่องมือรับประกันความถูกต้องของ Session Token
  * **multer:** ไลบรารีสำหรับกรองนามสกุลและจำกัดขนาดรูปภาพอัปโหลด
  * **cookie-parser:** โมดูลแกะข้อมูลโทเค็นความปลอดภัย JWT ออกจากส่วนหัวคุกกี้
